# MyStar Café – Café Ordering System

A simple console-based café ordering system developed using Java.

## Features

- Display café menu with item names and prices
- Allow customers to select food and drinks
- Accept item quantities
- Support multiple orders
- Calculate individual subtotals and the grand total
- Generate a receipt after ordering

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Array
- ArrayList
- Scanner
- Loops and Methods

## Project Structure

```text
MyStarcafe/
├── src/
│   └── App.java
├── bin/
└── README.md
```

## How to Run

1. Open the project folder in Visual Studio Code.
2. Open the terminal.
3. Compile the Java source file:

```bash
javac -d bin src/App.java
```

4. Run the application:

```bash
java -cp bin App
```
